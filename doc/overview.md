# 目的

インデックス投資家のモチベーション維持にフォーカスしたローカル完結・サーバーレス志向の資産可視化アプリです。初期リリースでは **グラフ化・資産連携・安定起動** に領域を絞り、詳細な損益分析やフィルタリングは後続フェーズで検討します。

# 全体アーキテクチャ

- **UI**: Next.js 14（App Router）
- **ストレージ**: SQLite（Docker コンテナ内ボリュームで永続化）
- **ORM**: Prisma
- **グラフ描画**: Recharts
- **データ取得**: コネクタ方式で Tier 分類  
  - Tier 1: 公式 API / 代行 API（OAuth / トークン）
  - Tier 2: セッションログイン（ID/Pass/2FA をローカル保存）
  - Tier 3: コンテナ内 Chromium（Puppeteer）でスクレイピング、またはユーザー端末で取得した JSON/CSV を取り込む
- **認証/暗号化**: 端末ローカルのパスフレーズで AES-GCM 暗号化
- **バックグラウンド同期**: なし（ユーザー操作時のみ）
- **レート参照**: 公開レート API または閲覧画面の換算値を採用

データは端末外へ送信しない設計で、コンテナ停止後もボリューム経由で DB を保持します。

# 主要ユーザーフロー

1. 初回起動でパスフレーズを設定し、機微情報を暗号化
2. 口座を追加（カテゴリ・取得方式・識別用ラベルなどを登録）
3. ダッシュボードの「連携する」ボタンを押す
   - ブラウザで noVNC (NEXT_PUBLIC_NOVNC_URL) を開き、仮想デスクトップ上の Chromium から楽天サイトにログイン
   - ログイン完了後、サーバー側 Puppeteer が資産合計を取得し口座データを更新
4. ダッシュボードへ即時反映  
   - 円換算の総資産推移グラフ
   - 資産配分グラフ
   - 総損益・総入金額・評価額カード
5. 同期失敗時は該当口座を明示して通知し、SyncLog に記録

# 画面要件（初期実装）
- **ダッシュボード**: 総資産カード + グラフ 2 種（総資産推移・資産配分）
- **口座管理**: 口座追加フォーム + 一覧表示
- **設定**: パスフレーズ設定 UI・DB エクスポート案内・ログ確認導線（拡張予定）

# 同期ポリシー
- デフォルトはユーザー手動同期のみ（将来的にクールダウン表示や定期同期を検討）
- 失敗時は SyncLog に記録し、対象口座を名指しで通知

# コンプライアンス初期方針
- 個人情報はローカルのみ保持し、外部送信しない
- スクレイピングはユーザー自己責任。初期状態では OFF
- 規約/ポリシーにはローカル処理・暗号化保存・自己責任・問い合わせ導線を明記
